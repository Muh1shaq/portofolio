# Images Directory

## Profile Image
Place your profile photo here as `profile.jpg` or `profile.png`
Recommended size: 400x400px or 500x500px

## Project Screenshots
Place project screenshots in the `projects/` subdirectory
Naming convention: project-id.png (e.g., smartify.png, rsis.png, game-2d.png, dll.png)
Recommended size: 1200x800px or 16:9 aspect ratio
